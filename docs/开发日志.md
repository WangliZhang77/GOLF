### 五、遇到的问题与解决
1. Docker Desktop 引擎未启动：首次 `docker compose up` 报 pipe 连接失败 → 启动 Docker Desktop 后引擎就绪，成功拉取 postgres:16 并运行（healthy）。
2. pydantic-settings 解析 `cors_origins` 列表报错：从 `.env` 读取 list 字段时会先尝试 JSON 解码导致 `JSONDecodeError` → 用 `Annotated[list[str], NoDecode]` 跳过内置解码，改由 `field_validator` 按逗号切分。
3. 前端 `tsc -b` 报 TS6310：被引用的 composite 项目 `tsconfig.node.json` 不能 `noEmit` → 移除该字段，两个前端均修复后构建通过。
4. 用 `127.0.0.1` 直连前端端口连不上：Windows 上 Vite 绑定 `localhost`（IPv6）→ 用 `localhost` 访问前端端口即可（后端仍监听 127.0.0.1:8000）。
5. 中文在 PowerShell 控制台显示乱码：仅为终端编码显示问题，接口返回的 UTF-8 内容正确，浏览器正常。
