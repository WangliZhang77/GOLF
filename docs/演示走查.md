# V1.0 演示走查手册

面向理事会/技术评审的 15–20 分钟端到端演示脚本。覆盖组织、会员、活动、财务、消息五大模块的跨模块打通。

## 一、准备

```bash
# 1. 启动数据库
docker compose up -d db

# 2. 后端（端口 8000）
cd backend
.venv\Scripts\Activate.ps1
alembic upgrade head
python -m app.seed

# 3. 管理后台（端口 5173）
cd admin-web && npm install && npm run dev

# 4. 会员端（端口 5174）
cd member-web && npm install && npm run dev
```

`python -m app.seed` 会幂等生成完整演示世界：总会 + 奥克兰分会 + 奥克兰A队 + 多角色账号 + demo 会员（含 5 次历史出勤、账单、消息、已报名活动）。

## 三、场景 A — 会员端（demo / demo123456，端口 5174）

| 步骤 | 操作 | 预期 | 对应 API |
|------|------|------|----------|
| 1 | 登录 | 首页显示后端连通 | `POST /api/auth/login` |
| 2 | 活动 Tab | 已报名「演示周末下场」 | `GET /api/activities` |
| 3 | 我的 → 账单 | 待缴会费 + 已缴历史 | `GET /api/finance/me/bills` |
| 4 | 我的 → 消息 | 未读角标；点「标为已读」后角标减少 | `GET /api/messages/me`、`POST /api/messages/me/{id}/read` |
| 5 | 切换 EN | 账单/消息文案切换英文 | 前端 i18n + 双语字段 |

## 四、场景 B — 管理后台（admin / admin123456，端口 5173）

| 步骤 | 操作 | 预期 | 对应 API |
|------|------|------|----------|
| 1 | 组织架构 | 奥克兰分会 + 奥克兰A队 | `GET /api/organizations` |
| 2 | 会员 | 查看 demo 档案（含隐私） | `GET /api/members` |
| 3 | 活动 | 查看报名列表与签到二维码 | `GET /api/activities/{id}/registrations` |
| 4 | 财务 | 记一笔、汇总卡片（收入/支出/净额） | `POST /api/finance/ledger`、`GET /api/finance/ledger/summary` |
| 5 | 消息 → 发送催缴 | 选 demo 或「一键催缴全部欠费」 | `POST /api/messages/dues-reminder` |
| 6 | 回会员端 | demo 收到新催缴消息 | `GET /api/messages/me` |

## 五、场景 C — 跨模块闭环（转正）

demo 会员入会满 3 个月、出勤 5 次（种子已备），但有待缴会费。

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 财务：对 demo 的待缴会费点「标记已收」 | `is_paid=true` |
| 2 | 超管/队长：对 demo 执行「转正」 | `promoted=true`，等级变正式会员 |

若跳过步骤 1 直接转正，应返回 `promoted=false`（存在未缴费用），演示「无欠费」硬规则。

## 六、场景 D — 角色隔离（可选）

- `council / demo123456`：登录后仅见奥克兰分会的会员与活动；无法跨分会操作。
- `finance / demo123456`：可见财务台账与催缴；无组织架构写权限。
